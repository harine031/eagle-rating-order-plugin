# Flexible Sort Board

Eagleで画像を柔軟に並べ替え、評価・名前・タグ・プレビューをまとめて操作するWindow Pluginです。

Eagle標準機能で評価順に並べたあと、手動モードへ切り替えて、画像をドラッグ＆ドロップで自由に並べ替えられます。

## ダウンロード

最新版は[GitHub Releases](https://github.com/harine031/eagle-rating-order-plugin/releases/latest)からダウンロードできます。

1. `Flexible-Sort-Board-*.eagleplugin`をダウンロードします。
2. Eagleを起動し、プラグイン管理画面を開きます。
3. ダウンロードした`.eagleplugin`ファイルを読み込みます。

## 主な機能

- 選択中フォルダの画像を表示
- 評価、名前、日時、サイズ、解像度、拡張子などで並べ替え
- ドラッグ＆ドロップによる手動並べ替え（複数選択をまとめて移動可能）
- 並び順のlocalStorage保存
- 現在の順番で連番リネーム
- 選択画像だけの連番リネーム
- 評価を0〜5へ変更（画面ボタン、数字キー、テンキー）
- 評価フィルターと各評価の該当件数表示
- 評価なし画像をまとめてEagleのゴミ箱へ移動
- Ctrl＋クリックによる複数選択
- 選択画像のタグ一括追加・削除
- 拡大プレビュー、左右移動、ズーム、回転、スライドショー
- 拡大画像をEagle本体で開く

## 導入方法

1. Eagleを起動します。
2. プラグイン管理画面を開きます。
3. `Flexible-Sort-Board-1.1.1.eagleplugin`を読み込みます。
4. 画像が入ったフォルダをEagleで選択します。
5. プラグインを起動します。

## 基本操作

- 画像をクリック：単一選択
- `Ctrl`＋クリック：複数選択（MacはCommand）
- 選択済み画像をドラッグ：選択画像を表示順のまままとめて移動
- ダブルクリック：拡大プレビュー
- `Space`：プレビューの開閉
- `←` / `→`：プレビュー中の前後移動
- `Esc`：プレビューを閉じる
- `0`〜`5`：選択画像の評価変更
- `Delete`：選択画像をEagleのゴミ箱へ移動

## 名前変更

「後半の名前」に`name`と入力し、桁数を3にすると、次のようになります。

```text
001_name
002_name
003_name
```

拡張子は変更しません。

## 注意事項

- 削除操作は完全削除ではなく、Eagleのゴミ箱への移動です。
- 評価変更にはEagleのローカルAPIを使用するため、Eagleを起動した状態で利用してください。
- プラグイン内の手動順は、Eagle本体のカスタム順を直接変更するものではありません。Eagle本体で同じ順番を再現する場合は、連番リネーム後に名前順で表示してください。
- 大量の画像を処理する場合は、対象フォルダを分けて操作することを推奨します。
